# 🧠 Brain Stroke Detection System

## 🔍 Overview
AI-based web application to predict stroke risk using Machine Learning.

## 🚀 Features
- Stroke risk prediction
- Confidence score
- Interactive UI
- Flask-based web app

## 🧠 Model
- Algorithm: Random Forest
- Accuracy: ~93%
- Dataset: Stroke dataset

## ▶️ Run Project
pip install -r requirements.txt
python app.py

## 📌 Inputs
- Age
- Hypertension
- Heart Disease
- Glucose Level
- BMI
